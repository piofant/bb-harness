# Инструкции для bb

Положи в `<каталог данных bb>/AGENTS.md` (обычно `~/.bb/AGENTS.md`) — bb подмешивает его во все треды.

<!-- chat-names:start -->
# Названия чатов
Новый чат, которому уже нужны инструменты (а также по просьбе или при полной смене задачи), назови одной командой: `bb thread update --self --title '<дата> | <суть, 2–4 слова> | <область>'`. Название, которое пользователь задал руками, не перетирай.
<!-- chat-names:end -->

# Ссылки на файлы
Файл в ответе — только markdown-ссылкой с абсолютным путём: `[notes.md](/home/me/notes/notes.md)`. Голое имя (`notes.md`) bb ищет в рабочей папке треда и показывает «File not found». Относительный путь — только для файлов внутри рабочей папки треда.
