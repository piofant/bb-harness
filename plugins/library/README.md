# Библиотека — плагин bb

*Library — your agents' knowledge base as a pixel library in the bb side panel.*

База знаний агентов в стиле таверны: стопка книг в левой панели bb. Рассчитан
на базу из [`knowledge-base/`](../../knowledge-base) этого репозитория
(`INDEX.tsv`, `cards/`, `state/`, `CONFLICTS.md`, CLI `kb`).

- **Зал**: пять стеллажей — разделы базы (по умолчанию Агенты, Инфра,
  Проекты, Инструменты, Заметки — список в `lib/kb.ts`) с числом карточек. У каждого свой библиотекарь; если карточки его
  раздела подкладывали агентам за последний час, он носит их к столам, над
  головой — сколько. Клик по библиотекарю фильтрует доску по разделу.
- **Лампа** на столе в центре — здоровье базы: зелёная, жёлтая, красная.
- **Доска** сверху, три вкладки:
  1. **читают** — карточки, которые хук подсказок подкладывал в сессии
     (`state/kb-hint.jsonl`), свежие сверху, сколько раз и когда;
  2. **новое** — карточки, добавленные и обновлённые за 3 дня (git), и
     заметки агентов, которые ждут сводчика;
  3. **здоровье** — статус и проблемы из `state/health.json`;
  4. **управление** — что требует вашего решения:
     - **Решить**: открытые пункты `CONFLICTS.md`. Раскройте пункт, выберите
       «верна первая / вторая / обе в разных условиях / свой ответ», подтвердите —
       плагин создаёт тред-поручение, агент оформляет решение по правилам базы
       (`decisions/`, правка карточек, закрытие пункта, коммит под `repo.lock`).
     - **Конвейер**: последний прогон забора, сводчика, индекса, ежедневного и
       недельного прогона с причиной простыми словами; «прогнать» запускает
       `kb ingest all`, `kb daily` или `kb index`.
     - **Ничего не сохранили**: недавние треды, из сессий которых в базу не
       пришло ни одной заметки; «сохранить в базу» просит агента этого треда
       записать устойчивое через `kb note` (идея из bb-plugin-wiki).
- **Читалка**: клик по строке открывает карточку справа; ссылки `[[имя]]`
  ведут на другие карточки. «в панели ↗» открывает файл в панели bb — с
  установленным Obsidian at Home там превью ссылок и правка.

Сам плагин базу не меняет: решения оформляет агент в отдельном треде, а
прогоны — штатные команды `kb`. Обновление — раз в минуту.

## Установка

```
bb plugin install ./plugins/library --yes
```

Настройки плагина: **Каталог базы знаний** (по умолчанию `$KB_ROOT` или
`~/agent-knowledge`), проект для тредов-поручений (пусто — первый), окна
«Новое» и «Ничего не сохранили» в днях. Для кнопки «прогнать» нужен `kb` в
`PATH`. Карточки с `sensitivity: restricted` в библиотеку не попадают.

## Разработка

```
bb library status
npm test && npx tsc --noEmit
node scripts/build-library.mjs <tilesets>   # пересобрать карту из тайлсетов Ninja Adventure
node scripts/gen-assets.mjs && bb plugin build && bb plugin reload library
```
