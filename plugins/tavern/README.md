# Таверна — плагин bb

*Tavern — the skills your agents use, as pixel characters walking around a tavern in the bb side panel, with a day/night cycle and a TV recap of the last 3 days.*

Таверна скиллов по мотивам [piofant.github.io/skills](https://piofant.github.io/skills/):
кружка в левой панели bb открывает зал, где пиксельные персонажи — это скиллы
из ваших сессий.

## Что на странице

- **Телевизор** над залом — «Помогаторы ТВ» за последние 3 дня, три канала
  кнопками под экраном:
  1. **Обзор** — одна фраза о главном и до 5 тем по смыслу (связанные треды
     склеены), каждая в одну строку: точка статуса (зелёная — готово, жёлтая —
     в работе, красная — застряло), название, итог. Клик — в тред.
  2. **Ждут тебя** — треды, где агент закончил вопросом или ошибкой и ответ
     ещё не прочитан: последний вопрос агента и кнопка в тред.
  3. **Табло** — проекты как команды (счёт — треды), игрок периода — самый
     частый скилл, топ скиллов.

  Обзор пишет `claude -p` (sonnet) раз в московские сутки по конспектам
  свежих тредов (до 30): превью сообщений пользователя и последних ответов
  агента, почты и телефоны вырезаются. ↻ — переписать сейчас (≈15 с, около
  5 центов).
- **Зал** — работают скиллы, которые звали за последние 3 часа (не меньше 5
  самых свежих, не больше 12). Ходят между местом и станцией у мебели;
  «!» над головой — их тред сейчас крутится.
- **Веранда** — отдыхают следующие до 10 скиллов по свежести; ночью спят.
- **Трактирщик у очага** — `chat-names`: его зовут в каждой сессии, поэтому
  он не вытесняет остальных.
- **Часы** в правом верхнем углу: время по Москве, рассвет и закат. Свет в зале
  идёт за высотой солнца: днём ровно, в сумерках тепло, ночью темно, горят
  очаг, свечи и фонари веранды. Кнопка «Время: сейчас» в шапке листает превью
  рассвет → день → закат → ночь.
- **Карточка** по клику на персонажа: имя (✎ — переименовать, пустое —
  вернуть прежнее), скилл, описание из SKILL.md, сколько раз звали, кнопка
  «Открыть тред» с последним вызовом.

## Откуда данные

Фоновый сервис раз в 30 секунд дочитывает ленты тредов bb (только новые
события после сохранённого курсора) и ищет вызовы скиллов: инструмент `Skill`
у Claude Code и чтение `…/skills/<имя>/SKILL.md` у Codex и других. Первый проход
по истории за 30 дней занимает около двух минут. Всё хранится в базе плагина.

Для обзора в модель уходят превью сообщений видимых тредов за период
(сабагенты и скрытые треды — нет), почты и телефоны вырезаются. Каждая
попытка пишется в `~/.bb/plugins/tavern/logs/plugin.log`: модель, сколько
тредов, размер промпта, длительность, итог.

Настройки читаются при загрузке: после `bb plugin config tavern set …`
сделайте `bb plugin reload tavern`. Увеличение глубины истории не дочитывает
уже пройденные треды — для этого удалите кеш перезагрузкой с новой версией.

## Имена

Имя и спрайт берутся по порядку: своё из карточки → персонаж с сайта
таверны (`data/tavern-characters.json`) → словарь в `lib/personas.ts` →
придумывается из названия скилла. Одинаковые имена на сцене получают «II».

## Установка

```
bb plugin install ./plugins/tavern --yes
```

Нужен `claude` (Claude Code CLI) в `PATH` или в `~/.local/bin` — только для
обзора на телевизоре; остальное работает без него. Время и солнце — по
Москве (UTC+3), координаты — в `lib/sun.ts`.

## Команды

```
bb tavern list          # кто работает и отдыхает
bb tavern scan          # перечитать ленты сейчас
bb tavern tv --refresh  # табло, обзор и советы; переписать обзор
bb plugin config tavern # настройки: окна, лимиты, трактирщик, модель
```

## Разработка

```
npm test                # vitest: солнце, разбор вызовов, сцена, имена, табло
npx tsc --noEmit
node scripts/gen-assets.mjs   # после замены картинок в assets/
bb plugin build && bb plugin reload tavern
```
