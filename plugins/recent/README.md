# Недавние — плагин bb

Фокус-страница как «Recent» в Android-приложении bb: пункт «Недавние» (часы)
в левой рейке.

- **Не просмотрено** — корневые треды, где агент закончил (idle/error), а ты
  ещё не открыл: как синяя точка в сайдбаре bb (`(lastReadAt ?? 0) <
  latestAttentionAt`), плюс треды, которые ждут ответа
  (`hasPendingInteraction`). Свежие сверху.
- **Недавние** — остальные корневые треды по последней активности
  (`latestAttentionAt`; идущие сейчас — наверху), по 12, «Показать ещё» +12.
- Дочерние, архивные и скрытые треды не показываются.
- Заголовок `дд.мм | тема | область` показывается как «тема», полный — в
  подсказке. Серая плашка — область из
  `~/.agents/skills/chat-names/areas.json` (или `BB_AREAS_PATH`) (по ярлыку в заголовке → по
  `projects` → по `~/.local/state/chat-names/area-cache.json` (или `BB_AREA_CACHE_PATH`)). Нет файла
  или он битый — плашек нет.
- Внизу — штатный композер bb; после отправки открывается новый тред.
- Обновление — по живым событиям тредов, без сокета — опрос раз в 10 с.

```
npm test                      # lib/recent.ts
npx tsc --noEmit
bb plugin build && bb plugin install . --yes
bb plugin remove recent       # удалить
```
