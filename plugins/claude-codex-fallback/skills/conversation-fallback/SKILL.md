---
name: conversation-fallback
description: Inspect or configure a connected BB logical conversation with automatic provider recovery.
---
Use `bb conversation-fallback list` or `status <thread-id>` for actual state. Enable only the thread the user selected. Use `recover <thread-id>` after reviewing a blocked operation, or `disable <thread-id>` to stop future handoffs. Open the activeThreadId as an ordinary native BB thread. Visible continuation children are grouped under their source in the sidebar; the Parent link retains access to source history. The configuration panel is not a replacement chat UI. Never claim an original thread changed provider. Never delete original queued user rows automatically. Never disable another recovery plugin to force a handoff. Credential repair belongs to the provider's auth workflow.
