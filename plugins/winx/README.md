# Фея дня — плагин bb

*Winx — which Winx fairy you are today, picked by Claude from what you did in bb today. Original pixel art.*

Волшебная палочка в левой панели bb: какая ты сегодня фея Винкс.

- Раз в московские сутки (при первом открытии страницы) плагин берёт
  сегодняшние треды и по превью просьб и итогов спрашивает `claude -p`,
  чья это фея: **Блум** (пожары и десять задач), **Стелла** (визуал и подача),
  **Флора** (забота и личное), **Муза** (тексты, музыка, видео), **Текна**
  (код и серверы), **Лейла** (потоки и переключения).
- На карточке: фея, почему она (с отсылкой к делам дня), заклинание на вечер
  и из кого состоит день в процентах. Внизу — неделя фей.
- «Пересчитать» — заново по делам на этот момент.
- Дел за день нет — фея по дате, без модели.

Картинки — оригинальные пиксельные феи (`scripts/gen-fairies.mjs` →
`assets/fairies/*.svg`), не кадры из мультфильма.

В модель уходят превью сообщений видимых тредов за сегодня, почты и
телефоны вырезаются. Каждая попытка — в `~/.bb/plugins/winx/logs/plugin.log`.

## Установка

```
bb plugin install ./plugins/winx --yes
```

Нужен `claude` (Claude Code CLI) в `PATH` или в `~/.local/bin`. Сутки — по Москве.

## Команды и разработка

```
bb winx today [--reroll]
npm test && npx tsc --noEmit
node scripts/gen-fairies.mjs && bb plugin build && bb plugin reload winx
```

Winx Club — торговая марка Rainbow S.r.l.; плагин — фанатский, без официальных изображений.
