# Области работы в bb

Как разложить сотни тредов bb по областям жизни и работы, не выбирая проект при каждом новом треде.

## Идея
- **Проект bb — только для живого кода.** Всё остальное — один «дом» (обычная папка-проект), внутри — папки областей, у каждой свой `AGENTS.md`: что сюда, где код, какие скиллы, куда класть артефакты. В корне дома — короткое оглавление ([пример](AGENTS.example.md)).
- **Агент сам определяет область.** На первом ответе он называет тред `дд.мм | задача | область` (скрипт [`rename.py`](scripts/rename.py)); область видна прямо в названии.
- **Лента, а не разделы.** Новые и разовые треды живут в общей ленте. Сразу в раздел уходят только области с флагом `auto` (в примере — «Дневник», чтобы личное не мелькало).
- **Постоянные треды переезжают сами.** Раз в день [`promote.py`](scripts/promote.py) (автоматизация bb) переносит в раздел области тред, к которому вы возвращались в ≥ 3 разных дня за 3 недели. Тред, который вы вынули из раздела руками, обратно не возвращается. Нет раздела у области — тред закрепляется.
- **Область без подписи** определяет дешёвая модель: Claude Haiku, при сбое — Codex (изолированный запуск, без вашего конфига и истории). Каждая попытка пишется в журнал без текста тредов.
- **Страница «Недавние»** — плагин [`plugins/recent`](../plugins/recent): короткий список свежих тредов как Recent в мобильном bb.

## Установка
1. Скопируйте `scripts/` и [`areas.json`](areas.json) в папку скилла названий чатов (по умолчанию `~/.agents/skills/chat-names/`; `areas.json` — рядом с `scripts/`) и поправьте области под себя: `key`, подпись `label`, раздел `section`, папка `folder`, `aliases` (подписи, которые агенты реально пишут), `projects` (id проектов bb с кодом), `auto` (раздел сразу).
2. В инструкции агентам (например, `<bb dataDir>/AGENTS.md`) добавьте правило: «назови тред одной командой `python3 ~/.agents/skills/chat-names/scripts/rename.py --task '<суть>' --project '<область>'`; области — оглавление `~/bb-workspace/AGENTS.md`».
3. Создайте разделы bb для областей и автоматизацию на каждый день:
   ```sh
   bb automation create --project <id дома> --name 'Главные треды → разделы' \
     --cron '0 9 * * *' --timezone Europe/Moscow --interpreter bash \
     --working-directory automation-storage --script 'python3 ~/.agents/skills/chat-names/scripts/promote.py'
   ```
   Сначала посмотрите кандидатов без изменений: `python3 promote.py --dry-run`.
4. Переменные: `CHAT_NAMES_STATE` (журнал и состояние, по умолчанию `~/.local/state/chat-names`), `CHAT_NAMES_INDEX` (оглавление для модели, по умолчанию `~/bb-workspace/AGENTS.md`), `CHAT_NAMES_CODEX_MODEL`.

Тесты: `cd scripts && python3 -m unittest test_rename test_promote`.

`rename.py` — доработка [chat-names Даниила Трабуна](https://github.com/danieltrbn/trabun-skills/blob/main/skills/chat-names/SKILL.md): добавлен роутинг в разделы по `areas.json`.
